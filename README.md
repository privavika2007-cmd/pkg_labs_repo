# Color Lab

Лабораторная работа 1 «Цветовые модели», вариант 5: **CMYK ↔ LAB ↔ HSV**.

Веб-приложение: цвет задаётся в любой из трёх моделей, две другие
пересчитываются автоматически.

## Запуск
ССЫЛКА https://color-lab-iota.vercel.app
Сборка и зависимости не нужны, но модули ES не грузятся по `file://`,
поэтому нужен локальный сервер:

```bash
python3 -m http.server 8080
```

Приложение — `http://localhost:8080/index.html`
Тесты — `http://localhost:8080/js/tests/tests.html` или `node js/tests/tests.js`.

## Структура

```
index.html            разметка
css/styles.css        оформление
js/model/             математика преобразований (matrix, whitepoints, colorspace, convert, cie)
js/viewmodel/         состояние цвета и настроек
js/view/              интерфейс, палитры, график МКО
js/tests/             тесты математики
```

## Что реализовано

- три способа задания цвета в каждой модели: ползунок, числовое поле, палитра;
- автоматический пересчёт всех моделей при изменении любой координаты;
- выбор источника освещения D65 / D50 / E, матрицы перехода считаются на лету;
- два способа получения матрицы: по первичным цветам и адаптацией Брэдфорда;
- цветоделение CMYK по UCR или GCR с регулировкой доли чёрной краски;
- обработка выхода за охват sRGB: Clipping и Scaling, предупреждение в интерфейсе;
- динамические градиенты на ползунках;
- график МКО с треугольником охвата sRGB, белой точкой и текущим цветом;
- 37 тестов математики преобразований.

Внешние библиотеки конвертации цвета не используются.
Подробный разбор — в файле `РАЗБОР_ЛАБЫ.md`.
